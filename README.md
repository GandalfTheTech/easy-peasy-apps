# Easy-Peasy Apps

**Useful ideas. Made simple.**

Easy-Peasy Apps builds simple, intuitive mobile apps for everyday situations: practical tools that are clear to use, reliable and privacy-aware.

Website: [easy-peasy-apps.com](https://easy-peasy-apps.com)

## About this repository

The source of the Easy-Peasy Apps website, a static site with no build step.

| File | Purpose |
|---|---|
| `index.html` | Homepage |
| `privacy-policy.html` | Privacy Policy |
| `terms-of-use.html` | Terms of Use |
| `styles.css` | Styling |
| `script.js` | Mobile menu and current year |

## Deployment

Hosted with GitHub Pages from the `main` branch (root). Push to `main` to publish changes.
